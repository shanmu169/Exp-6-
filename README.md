# Exp - 6 STUDENT ONLINE EXAM REGISTRATION SYSTEM

# AIM:
To study the problem statement and SRS document, and draw all the UML diagrams for the Student  Online Exam Registration System 
# SRS (Procedure):
# Step 1: Problem Identification
The main problem is the need for a fast, secure, and automated system that allows students to register for online examinations, view available examinations, select subjects, pay examination fees, and manage their examination registration details efficiently.

# Step 2: Requirement Analysis
Identify user needs: Student, Admin, Examiner, Payment Gateway
Define functional requirements:

Student registration and login,View available examinations,Subject selection,Examination registration,Examination fee payment,Payment verification,Examination,registration confirmation,Registration cancellation,Student examination record management,Examination and subject management,Examiner management
Define non-functional requirements:
Speed,Security,Reliability,Usability,Data integrity,Payment security
